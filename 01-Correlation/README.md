
STA553: Correlation Analysis
===========================

This folder contains learning materials for **STA553: Linear Statistical Models**, focusing on correlation analysis using Microsoft Excel and R.

Contents
========

1. Excel Master File
-----------------

The Excel master file provides step-by-step guidance for calculating correlation coefficients using Microsoft Excel.

It covers the following methods:

- Pearson correlation coefficient
- Spearman rank correlation coefficient
- Kendall's tau correlation coefficient

The file helps students understand how to obtain correlation coefficients using Excel before performing the analyses in R.

-----------------
2. R Scripts
-----------------

R scripts for performing the following correlation analyses:

- **Pearson Correlation** — Measures the strength and direction of a linear relationship between two variables.
- **Spearman Rank Correlation** — Measures the strength and direction of a monotonic relationship using ranked data.
- **Kendall's Tau Correlation** — Measures association based on concordant and discordant pairs.

-------------------
Learning Objectives
-------------------

By the end of this topic, students should be able to:

1. Calculate correlation coefficients using Microsoft Excel.
2. Perform Pearson, Spearman, and Kendall correlation analyses using R.
3. Interpret and compare the results obtained from different correlation methods. Interpret correlation coefficients using Excel and perform correlation analysis using R.
